# AI Student Feedback Intelligence System

An AI-powered system that analyzes student textual feedback using NLP, clustering, and Gemini API to generate actionable education insights. Built with pandas, scikit-learn, Streamlit, and Google Gemini.

## Features
- Feedback text clustering (TF-IDF + KMeans)
- Automated AI report generation (Gemini 2.5 Flash)
- Interactive web interface (Streamlit)

## Run
pip install -r requirements.txt
streamlit run app.py
